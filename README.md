# Нейро-Мастерская

Каталог бесплатных нейросетей для создания контента с телефона (iPhone).
Один самодостаточный `index.html`: тёмная «стеклянная» тема в стиле iOS, оффлайн,
без внешних библиотек и шрифтов. Всё на русском, для новичка.

## Что внутри

| Вкладка | Что там |
|---|---|
| **Каталог** | 81 инструмент в 12 категориях + поиск, фильтры («Без VPN», «Для старта», «Есть приложение»), избранное |
| **Как начать** | 14 пошаговых гайдов: зарубежный Apple ID, безопасность, первая картинка, видео, монтаж, минусовка, текст под такт, YouTube |
| **Промпты** | 20 готовых промптов с кнопкой «Скопировать» |
| **Моё** | Избранное, чек-лист «План первого ролика», светлая тема, сброс |

## Структура

```
media-ai-catalog/
├── index.html            ← собранное приложение (то, что открывается на телефоне)
├── apple-touch-icon.png  ← иконка для домашнего экрана iPhone
├── _tools/
│   ├── data.json         ← ВЕСЬ контент: инструменты, гайды, промпты, чек-лист
│   ├── template.html     ← дизайн + код приложения (плейсхолдер __DATA__)
│   ├── build.py          ← сборка + валидация: data.json + template.html → index.html
│   └── make_icon.py      ← генератор иконки (чистый Python, без зависимостей)
└── .nojekyll             ← чтобы GitHub Pages не трогал файлы
```

## Как править и пересобирать

```bash
# 1. Отредактируй _tools/data.json (инструмент, гайд, промпт, пункт чек-листа)
# 2. Пересобери:
python _tools/build.py
# 3. Проверь index.html в браузере (лучше в режиме телефона 390×844)
```

`build.py` сам проверит данные: уникальные `id`, существующие категории,
ссылки `https://`, обязательные поля. При ошибке `index.html` не собирается —
так на сайт не попадёт ничего сломанного.

Иконку можно перегенерировать: `python _tools/make_icon.py`.

## Поля инструмента (data.json → tools[])

- `id` — уникальный, латиницей; `cat` — id категории; `name`, `emo`, `url`
- `tagline` — одна строка «для чего лучше всего»; `what` — что это простыми словами
- `freeText` — что даёт бесплатно (лимиты); `warn` — предупреждение (необязательно)
- `vpn` — `false` = работает из России без VPN (зелёный бейдж)
- `ios` — есть приложение для iPhone; `free` — `full` / `limited` / `paid`; `diff` — 1/2/3 (Легко/Средне/Сложно)
- `watermark`, `commercial`, `where` — плашки «Водяной знак / Можно зарабатывать / Где работает»
- `steps[]` — пошагово «Как начать»; `plus[]` / `minus[]`; `alt[]` — id похожих инструментов
- `keys` — слова для поиска (русские синонимы!); `star: true` — значок «⭐ Для старта»

## Публикация (GitHub Pages)

```bash
cd media-ai-catalog
git init -b main
git add -A
git commit -m "Нейро-Мастерская: каталог"
# Создай ПУСТОЙ репозиторий на github.com (например media-ai-catalog), затем:
git remote add origin https://github.com/<логин>/media-ai-catalog.git
git push -u origin main
# На GitHub: Settings → Pages → Source: Deploy from a branch → main / (root) → Save
```

Через пару минут сайт будет доступен по адресу
`https://<логин>.github.io/media-ai-catalog/` — открыть в Safari на iPhone и
«Поделиться → На экран Домой». Иконка и название подтянутся из мета-тегов.

## Актуальность

`meta.checked` в data.json — дата проверки лимитов. Бесплатные тарифы меняются
часто: перед крупным обновлением стоит перепроверить ключевые сервисы
(Kling, Suno, Шедеврум, GigaChat, CapCut) по их сайтам.
